# FrenchMB
Disposition de clavier AZERTY Windows avec caractères latins liturgiques.

Created with MS Keyboard Creator 1.4 for Windows 10/11.

Guillemets francais (« ») = AltGr+< and AltGr+! 

Guillements anglais (“ ”) = AltGr+Shift+< and AltGr+Shift+!

Apostrophe = Shift+²

á, Á = AltGr+A, AltGr+Shift+A
É = AltGr+Shift+E
í, Í = AltGr+I, AltGr+Shift+I
ó, Ó = AltGr+O, AltGr+Shift+O
ú, Ú = AltGr+U, AltGr+Shift+U
ý, Ý = AltGr+Y, AltGr+Shift+Y

Ligatures OE, AE sans accent (æ, Æ, œ, Œ) = AltGr+Q, AltGr+Shift+Q, AltGr+L, AltGr+Shift+L

Ligatures OE (minuscule seulement) et AE avec accent (ǽ, Ǽ, œ́) = AltGr+S, AltGr+Shift+S, AltGr+M
